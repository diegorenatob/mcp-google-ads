## Changes after the first release

- **Place-biased keyword research** (`locations` on `autocomplete_keywords` / `research_keywords`):
  covers local intent on Explorer, where Google Ads keyword themes only filter by country (and
  return nothing for queries containing a place name, so local variants come from Autocomplete only).
- **Account allowlist** (`GOOGLE_ADS_ALLOWED_CUSTOMER_IDS`): the server only queries the accounts
  listed in `.env`. Unit tests: 25/25.

## Risks

| Risk | Impact | Mitigation |
|---|---|---|
| Google refresh token expires every 7 days (consent screen in Testing) | All Google tools fail with `invalid_grant` | `api_status` reports it; `npm run google:auth` renews in 1 min; long-term: publish consent screen during brand verification |
| Autocomplete endpoint is unofficial | Could rate-limit or change | Concurrency cap, cache 24 h, graceful degradation (other sources still answer) |
| Explorer quota 2,880 ops/day | Heavy use blocked | Local budget counter + cache |
| Secret leak in public repo | Credential compromise | `.gitignore`, gitleaks local + CI, GitHub push protection, first-push checklist |
| Claude connector spec changes | Login breaks | Built on SDK auth router; docs links in `CLAUDE_WEB.md` to re-check |
| `data/` volume lost on redeploy | Connector must be reconnected | Bind-mount `./data`; documented |
| No search volume on Explorer | Weaker keyword prioritization | Multi-source signal count; Phase 8 adds volumes |
